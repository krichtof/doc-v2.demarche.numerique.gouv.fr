# Modifier son formulaire

## Modifier l’ordre des champs

Il est possible de modifier l’ordre des champs en les faisant monter ou descendre dans le formulaire. Pour ce faire, cliquez sur les flèches situées à gauche du champ ou en utilisant la liste déroulante "déplacer le champ" comme suit :
